# Full Stack Development — Lab Assignment (13 Tasks)

## Folder Structure

### Frontend Tasks (Open `index.html` directly in browser)
1. `01-concentric-circles/` — 3 concentric circles (radii 10px, 20px, 30px) in different colors (CSS & Canvas).
2. `02-ten-horizontal-cards/` — 10 cards with top image, title, and description aligned horizontally via Flexbox.
3. `03-todo-list/` — To-Do list with checkbox, Move Up, Move Down, and Delete buttons.
4. `04-chessboard-js/` — Dynamic 8x8 Chessboard UI where all HTML elements and CSS properties are created in JavaScript.
5. `05-snake-ladder-game/` — Playable 2-player Snake & Ladder game (1–100 board, dice, snakes, ladders).
6. `06-random-jokes-api/` — Random Joke Generator fetching jokes from `official-joke-api.appspot.com`.
7. `07-universities-by-country-api/` — University finder by country fetching name, state, and website from `universities.hipolabs.com`.

### Backend & Full-Stack Tasks (Node.js + Express)
Run inside each folder:
```bash
npm install
npm start
```
8. `08-express-routes-template-engine/` — Express app with 7 routes (GET & POST) + EJS template engine (`http://localhost:3008`).
9. `09-express-restful-crud-products/` — Express RESTful CRUD on products (`name`, `price`, `description`) (`http://localhost:3009`).
10. `10-express-api-csr-products/` — Express JSON API (`id`, `name`, `price`, `rating`) + Client-Side Rendered frontend (`http://localhost:3010`).
11. `11-express-mongodb-crud-products/` — Express + Mongoose + MongoDB RESTful CRUD (`http://localhost:3011`, requires MongoDB running).
12. `12-ecommerce-app/` — Full-stack E-Commerce app with Storefront, Cart, Payment, Successful Orders, and Seller Master Panel (`http://localhost:3012`).

### React Task
13. `13-react-portfolio/` — Personal Portfolio Website built with React + Vite:
```bash
cd 13-react-portfolio
npm install
npm run dev
```
